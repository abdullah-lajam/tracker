# DMO Tracker

عميل منصة متتبع أعمال مكتب إدارة البيانات.

## التوزيع

يتم توزيع عميل Windows عبر GitHub Releases، بينما تبقى بيانات التشغيل المشتركة داخل SharePoint / OneDrive ولا تُرفع إلى هذا المستودع.

## البنية

- Local Client: يثبت محليًا على جهاز المستخدم.
- Shared Workspace: يحتوي البيانات والمرفقات والنسخ الاحتياطية ويُزامن عبر OneDrive.

> لا يحتوي هذا المستودع على بيانات المهام التشغيلية.
